## Executive Summary

This report delivers an empirical multivariate analysis of household financial health using a dataset of 150 household observations across 14 financial and psychological metrics. Using dimension-reduction techniques (Principal Component Analysis and Exploratory Factor Analysis), unsupervised machine learning (Hierarchical and K-Means Clustering), and inferential hypothesis testing (MANOVA and univariate ANOVA), we construct a robust taxonomy of household financial wellbeing.

The findings reveal three distinct socio-economic segments—Financially Stressed, Financially Moderate, and Financially Secure—providing actionable insights for customized financial advisory interventions and policy framework design.
