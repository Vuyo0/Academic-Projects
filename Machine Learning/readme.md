## Executive Summary

### Assignment 1 : Regression Models

Predicting public bicycle sharing demand is vital for urban mobility optimization, fleet rebalancing, and municipal resource planning. This study investigates the Seoul Bike Sharing Demand dataset to model hourly rental counts using environmental, seasonal, and temporal predictors.

We systematically execute six statistical learning tasks:

Exploratory Data Analysis (EDA) & variable categorization.

Analytical Problem Formulation (framing core domain questions).

Data Preprocessing & Feature Engineering (handling non-functioning operational days, dummy encoding, and Z-score standard scaling).

Simple Linear Regression (SLR) diagnostics across univariate predictors.

Multiple Linear Regression (MLR) model selection and variance evaluation.

Penalized Regression & PyTorch Neural Regression Diagnostics (comparing OLS, Ridge, LASSO, ElasticNet via Cross-Validation and custom PyTorch optimization).
